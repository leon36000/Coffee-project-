# HermesClaw Project Source Pack

Upload the Markdown files in this `source/` directory to the project knowledge/source area. Paste `../PROJECT_INSTRUCTIONS.md` into the project's custom instructions if that field is available.

Recommended initial read order: `00` -> `01` -> `02` -> `03`.

The `raglite/` directory is optional local retrieval infrastructure. The source files remain canonical even when RAGLite is not installed.
