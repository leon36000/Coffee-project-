# HermesClaw Agent Startup Checklist

**Authority:** operational checklist

Before substantive work:

- [ ] Read `00_PROJECT_CONSTITUTION.md`.
- [ ] Read `01_CANONICAL_FACTS.md`.
- [ ] Read `02_CANONICAL_DECISIONS.md`.
- [ ] Read `03_CURRENT_STATE.md`.
- [ ] Retrieve additional relevant source/RAG context for the task.
- [ ] Resolve the current official GitHub repository and branch live.
- [ ] Confirm that no operation targets GitSpace by accident.
- [ ] Distinguish verified current facts from historical statements.
- [ ] Identify the smallest capability/contract being changed.
- [ ] Determine what evidence will prove success before implementation.

Before finishing work:

- [ ] Run relevant current verification.
- [ ] Report failures honestly; do not hide them behind “best effort.”
- [ ] Update current state if operational truth changed.
- [ ] Update canonical decisions only if a durable decision changed.
- [ ] Update handoff with exact commit/tests/blockers/next step.
- [ ] Rebuild RAG if canonical source changed.
